# screenshot_to_text

OCR-приложение на Tkinter: выберите файл изображения или вставьте скриншот через `Ctrl+V` — распознанный текст появится в окне и сразу скопируется в буфер. Есть перевод на русский, английский, украинский и немецкий.

## Быстрый старт

```bat
python -m venv venv
venv\Scripts\pip install -r requirements.txt
start.cmd
```

`start.cmd` запускает `pythonw` из venv (или системный), без консоли. Прямой запуск: `venv\Scripts\python main.py`.

## Tesseract

Библиотека Python не включает движок OCR: установите Tesseract-OCR отдельно. Пуск ищется так: переменная `TESSERACT_CMD` → `PATH` → стандартные папки (`C:\Program Files\Tesseract-OCR`, `C:\Program Files (x86)\...`, `%LOCALAPPDATA%\Programs\...`, `D:\Program Files\...`). Если Tesseract не найден, приложение покажет ошибку и не откроется.

Языки выбираются автоматически: `rus+eng`, если установлены оба, иначе `rus` или `eng` (языковые данные ставятся вместе с Tesseract).

## Использование

1. «Выбрать файл» или `Ctrl+V` со скриншотом/картинкой (работает и с русской раскладкой).
2. «Распознать» — вставка из буфера сразу запускает OCR.
3. Готовый текст копируется в буфер; ниже можно выбрать язык и нажать «Перевести».

Перевод идёт через публичный эндпоинт Google Translate без ключа — нужен интернет. Длинный текст режется на куски по 4000 символов.

## Структура

| Файл | Роль |
|---|---|
| `main.py` | GUI, поиск Tesseract, OCR в потоке, перевод, буфер обмена |
| `requirements.txt` | Pillow, pytesseract, pyperclip |
| `start.cmd` | бесконсольный запуск |
| `screenshots\` | примеры скриншотов |
| `screenshot_to_text.lnk` | ярлык |

## Тесты

Автотестов нет; проверка вручную: распознать тестовый скриншот с русским и английским текстом, затем перевести его.
